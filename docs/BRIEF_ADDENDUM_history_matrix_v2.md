> 本書は `docs/BRIEF.md` の追補である。既存のデータスキーマ
> （`pmp_app_progress_v1` / `pmp_app_questions_v1`）は変更しない。
> 本書は先に渡した `docs/BRIEF_ADDENDUM_history_view.md`（一覧＋アコーディオン展開案）を
> **置き換える**。まだ未実装であれば旧ファイルは無視し、本書のみに従うこと。
> 実装済みの場合は、旧仕様のアコーディオン展開部分をマトリクス表に置き換える。

## 1. 目的

全問題について「これまで何回目にどうだったか（正解／不正解）」を、日時のような細かい情報を省いた**シンプルな表形式**で一望できるようにする。

## 2. 新規ビュー：「解答履歴」画面（マトリクス表）

### 2.1 画面へのアクセス経路

- トップ画面ヘッダーに「解答履歴」ボタンを追加。
- 各章カードに「履歴を見る」リンクを追加。押下するとその章に絞り込んだ状態で開く。

### 2.2 表の構成

**行**：問題（読み込み済みの`questions`全件。未解答の問題も含めて全件表示）
**列**：`1回目` `2回目` `3回目` …

- 列数は固定しない。**現在フィルタで表示されている問題群の中で、最大の`attempts`値**を列数とする（例：最も多く解いた問題が5回なら、列は「1回目」〜「5回目」の5列）。
- 全問未解答（列を作る根拠がない）の場合は、列を1つ（`1回目`）だけ表示し、全セル空欄とする。
- フィルタを変更して表示対象が変わった場合、列数（最大解答回数）も再計算して表を再構成する。

**行の左端（固定列）**：
- 章番号・問題ID（例：`第3章 問112`）
- 問題文冒頭12〜15字程度（省スペースのため短め）

**各セルの表示**：

| 状態 | 表示 |
|---|---|
| その回で正解 | `○`（緑） |
| その回で不正解 | `✕`（赤） |
| その回まで解いていない（`attempts`がその列数未満） | 空欄（`-`などのプレースホルダでもよいが、視覚的に薄く目立たせない） |

- セルの中身は`records[id].history[列番号-1].correct`の真偽値のみを見る。選択した選択肢や日時はこの表には出さない。
- **1問1行の高さは最小限**（40px程度）にし、多くの行を一度にスクロールで見渡せる密度にする。

### 2.3 レイアウト（横スクロール対応）

- 左端の「問題番号・問題文冒頭」列は**横スクロールしても常に見える位置に固定**する（CSSの`position: sticky; left: 0;`等）。
- 列（1回目・2回目…）が画面幅に収まらない場合は、**表全体を横スクロール**できるようにする（`overflow-x: auto`のコンテナで表をラップ）。
- 縦方向は通常のページスクロールでよい（行数が多いため）。

### 2.4 絞り込み・並び替えUI（画面上部に常設）

- **章フィルタ**：セレクトボックス。「すべての章」＋各章タイトル。章カードから遷移した場合はその章が選択済みの状態で開く。
- **ステータスフィルタ**：`すべて` / `未解答` / `直近正解` / `直近不正解`。`records[id].lastResult`基準で行を絞り込む（列の○✕表示自体には影響しない。あくまで「どの行を表示するか」のフィルタ）。
- **並び替え**：`問題番号順`（デフォルト） / `解答回数が多い順` / `解答回数が少ない順`。
- 該当件数を表示する（例：`該当 42問 / 全500問`）。

### 2.5 行の操作

- 各行の左端（問題番号・問題文）をタップすると、**その1問だけを対象にした復習セッション**を開始する。
- 復習セッションは、既存の演習／復習モードの描画関数を、対象問題1問だけの配列で呼び出す形で実装する（新しい描画ロジックを作らない）。
- アコーディオン展開・全履歴の時系列表示は**廃止**する（旧仕様の§2.4は不要）。

### 2.6 パフォーマンス

- 500行×数列程度のテーブルであり、通常のHTML `<table>`で問題ない。仮想スクロールやメモ化は不要。

## 3. 影響範囲

- 既存のデータスキーマ、演習画面、サマリー画面、既存の復習モード、データ管理画面のロジックには変更を加えない。
- 旧`docs/BRIEF_ADDENDUM_history_view.md`のうち、§2.4（アコーディオン展開・時系列表示）のみ本書の§2.5に置き換える。一覧画面自体のアクセス経路（§2.1）とフィルタの考え方（§2.4／本書の§2.4に相当）は概ね踏襲している。

## 4. 完成の定義

- [ ] トップ画面から「解答履歴」でマトリクス表画面に遷移できる
- [ ] 章カードの「履歴を見る」から、その章に絞り込まれた状態で開ける
- [ ] 表の列数が、表示中の問題群の最大解答回数に応じて動的に決まる
- [ ] 各セルが○（正解）／✕（不正解）／空欄（未到達）を正しく表示する
- [ ] 左端の問題番号列が横スクロール時も固定表示される
- [ ] 章フィルタ・ステータスフィルタ・並び替えが正しく機能する
- [ ] 行をタップすると、その1問だけの復習セッションが開始できる
- [ ] 500問全件表示時も動作が重くならない（実機で体感確認）
- [ ] iPhone（幅375px程度）で表の横スクロールが問題なく操作できる
