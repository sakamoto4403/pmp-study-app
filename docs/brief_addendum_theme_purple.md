# BRIEF追補：テーマカラーを紫（指定色）に統一（v3 / ティファニーブルー版を置き換え）

> 本書は **`pmp-study-app`専用**。`docs/BRIEF_ADDENDUM_theme_tiffany.md`を置き換える。
> `ds-kentei-study-app`には適用しない（そちらは引き続きティファニーブルーのまま）。
> まだティファニーブルーが未実装であれば旧ファイルは無視し、本書のみに従うこと。
> 実装済みの場合は、色の値だけを本書の内容に差し替える
> （構造・変数名・適用箇所の考え方は旧版と同じ）。
> 機能・データスキーマ・レイアウトには一切変更を加えない、色のみの変更である。

---

## 1. 色について

利用者が指定した紫色（画像から抽出）を採用する。

## 2. カラーパレット（確定・ティファニーブルー版から差し替え）

```css
:root {
  --color-primary: #b45ad3;        /* 指定紫色（メイン） */
  --color-primary-dark: #824198;   /* 濃色（ホバー・押下時、テキスト用） */
  --color-primary-light: #eedbf5;  /* 薄色（背景・バッジ用） */
  --color-primary-lighter: #faf5fc;/* さらに薄い背景用 */

  --color-danger: #ef4444;         /* 不正解・警告（赤系、変更しない） */
  --color-danger-light: #fee2e2;

  --color-text: #1f2937;
  --color-text-muted: #6b7280;
  --color-border: #e5e7eb;
  --color-bg: #ffffff;
}
```

- 変数名は旧版（ティファニーブルー／エメラルドグリーン）と同一のまま、**値のみ**をこの表のとおりに変更する。
- 既にティファニーブルー（`#0abab5`系）またはエメラルドグリーン（`#10b981`系）で実装済みの場合、それらの値を検索し、上記の値へ一括置換する形で対応する。

## 3. 適用箇所（変更なし・従来どおり）

対象箇所は変わらない：ボタン、演習画面・教科書モードの正解ハイライト、章ステータスバッジ、解答履歴マトリクス表の○セル、リンク、トップ画面の進捗表示のアクセント文字、`manifest.json`の`theme_color`。

## 4. 変更しないもの

- 不正解・警告表示の赤系配色は変更しない。
- 中立色（本文・背景・境界線）、レイアウト、機能ロジックは変更しない。

## 5. 完成の定義

- [ ] `style.css`のCSSカスタムプロパティの値が`#b45ad3`系に変更されている
- [ ] ティファニーブルー（`#0abab5`系）・エメラルドグリーン（`#10b981`系）の値がコード内に残っていない
- [ ] ボタン・正解ハイライト（演習画面・教科書モード両方）・章ステータスバッジ・解答履歴マトリクス表の○セル・リンク・進捗表示が新しい紫色で統一されている
- [ ] 不正解・警告表示の赤系は変更されていない
- [ ] `manifest.json`の`theme_color`が`#b45ad3`になっている
- [ ] 薄い背景色（`--color-primary-light`）に濃い文字色（`--color-primary-dark`または`--color-text`）を重ねて視認性が確保されている
- [ ] PC・iPhoneの両方で配色が正しく反映されていることを目視確認
