# BRIEF追補：教科書モードの導線をトップ画面に明示配置（v2）

> 本書は `docs/BRIEF_ADDENDUM_textbook_mode.md` §2.1 を**置き換える**。
> それ以外（§2.2〜§4：画面表示・目次・学習記録への非影響・パフォーマンス）は変更しない。

---

## 1. 背景

旧仕様（§2.1）では「トップ画面ヘッダーに教科書モードボタンを追加」「章カードに教科書で読むボタンを追加」としていたが、既存のヘッダー内ボタン（データ管理・解答履歴等）に埋もれて見つけにくい状態になっている。**教科書モードへの入り口を、他の機能ボタンと同列に並べず、独立した目立つセクションとして配置し直す。**

## 2. 新しいアクセス経路（§2.1の置き換え）

### 2.1 トップ画面に専用セクションを新設

トップ画面において、**「全体サマリー（ヘッダー）」の直下・「章一覧」の直前**に、教科書モードへの入り口として独立したセクションを配置する。

- 見出し：`教科書モードで読む`
- 一言説明：`解答・解説を見ながら、問題を通しで読めます（採点なし）`
- 章を選ぶボタン（章タイトルの一覧、または現状の演習用章一覧とは別に、教科書モード用の章選択リストをここに横並び／縦並びで表示）
- **見た目は他のボタンより大きく・背景色を付けるなどして、ヘッダー内の小さいボタン類とは明確に区別する**（例：カード状のセクションとして枠で囲む）

### 2.2 章カードからの導線（維持）

既存どおり、各章カードにも「教科書で読む」ボタンを残す（削除しない）。トップの専用セクションと章カードの両方から教科書モードに入れる状態にする。

### 2.3 ヘッダー内の旧ボタンの扱い

旧仕様でヘッダーに追加した「教科書モード」ボタンがある場合は、2.1の専用セクションと重複するため**削除してよい**（専用セクションに一本化する）。

## 3. 完成の定義（追加分）

- [ ] トップ画面の「全体サマリー」と「章一覧」の間に、教科書モード専用セクションが独立して配置されている
- [ ] セクションの見た目が、ヘッダー内の他のボタン（データ管理・解答履歴等）より明らかに目立つ
- [ ] セクション内から章を選ぶと、その章の教科書モード画面（既存の§2.2〜§2.4のロジック）が開く
- [ ] 章カードの「教科書で読む」ボタンも引き続き機能する
- [ ] iPhone幅（375px程度）でセクションのレイアウトが崩れない
