# BRIEF追補：教科書モード（問題と解答の通し読み）

> 本書は `docs/BRIEF.md` の追補である。既存のデータスキーマ
> （`pmp_app_progress_v1` / `pmp_app_questions_v1`）は変更しない。
> 既存の演習画面・復習モード・サマリー画面・データ管理画面のロジックにも変更を加えない。
> 完全に新規の閲覧専用ビューを1つ追加するだけの機能追加である。

---

## 1. 目的

演習（1問ずつ解答→採点）とは別に、**問題・正解・解説をあらかじめ全部表示した状態で、教科書のように上から下へ読み進められる閲覧モード**を追加する。暗記・通読用途であり、テストではない。

## 2. 新規ビュー：「教科書モード」

### 2.1 アクセス経路

- トップ画面ヘッダーに **「教科書モード」ボタン** を追加。押下すると章選択画面（または既存の章一覧を流用）に遷移し、章を選ぶとその章の教科書モード画面が開く。
- 各章カードに **「教科書で読む」ボタン** を追加（既存の「演習を始める」「もう一度解く」等と横並び）。押下すると、その章の教科書モード画面へ直接遷移する。

### 2.2 画面構成

- 画面上部：章タイトルを表示（例：`第3章 People②（コンフリクト・交渉・エンパワーメント）`）＋「トップに戻る」リンク
- その章の全問題を**id昇順で縦に連続表示**する。1問分の表示ブロックは以下の構成：

```
問101
プロジェクトの利益相反（conflict of interest）が疑われる状況に直面したとき、
PMIの倫理規定に照らして取るべき行動として正しいものはどれか。

ア  自分に有利になるよう状況を利用する
イ  問題が表面化するまで何もせず静観する
ウ  関係者に状況を開示し、影響を受ける当事者の判断を仰ぐ　← 正解（緑背景・チェックマーク）
エ  利益相反の事実を隠して通常どおり業務を進める

解説
プロジェクトの利益相反が疑われる状況に直面したとき、PMIの倫理規定に照らして
取るべき行動として正しいものは...
```

- **選択肢は非インタラクティブ**（クリックしても何も起きない、ラジオボタンやカードのホバー効果は付けない）。正解の選択肢のみ視覚的に強調する（背景色・チェックマーク等。演習画面の「正解」の見せ方と統一してよい）。
- 解説文は選択肢の直後に常時表示（クリックして開く必要はない）。
- 1問ごとに区切り線（`<hr>`等）を入れ、視覚的に区切る。

### 2.3 章内ナビゲーション（任意・推奨）

- 章の先頭に、問題番号へジャンプできる簡易目次を置く（例：`1 2 3 ... 50`のような番号リンクをページ内アンカーで並べる）。50問分をワンページで表示するため、目次があると読みたい箇所へすぐ移動できる。
- ページ最下部に「トップに戻る」「次の章を読む」（最終章では非表示）ボタンを設置する。

### 2.4 学習記録への影響（重要）

- **教科書モードでの閲覧は`records`・`chapterStatus`・`resumePointer`のいずれも一切更新しない。** 演習の進捗・正答率・解答履歴とは完全に独立した読み物として扱う。
- 教科書モードを開いたこと自体もログに残さない（閲覧履歴の記録機能は今回のスコープに含めない）。

### 2.5 パフォーマンス

- 1章50問分をまとめてDOMに描画して問題ない（仮想スクロール等は不要）。
- 章単位での表示とし、全500問を1ページに一括表示する機能は設けない（読み込み・スクロール量が過大になるため）。

## 3. 影響範囲

- 既存のデータスキーマ・演習画面・復習モード・サマリー画面・データ管理画面・解答履歴マトリクス表（`docs/BRIEF_ADDENDUM_history_matrix_v2.md`）には一切変更を加えない。
- 新規ビューの追加と、トップ画面・章カードへのボタン追加のみを行う。

## 4. 完成の定義

- [ ] トップ画面から「教科書モード」で章を選び、その章の教科書モード画面を開ける
- [ ] 章カードの「教科書で読む」から、その章の教科書モード画面へ直接遷移できる
- [ ] 章内の全問題が問題文・選択肢・正解ハイライト・解説とともに、id昇順で連続表示される
- [ ] 選択肢はクリックしても何も起きない（非インタラクティブ）
- [ ] 教科書モードを閲覧しても、章の進捗状況（`chapterStatus`）・正答率・解答履歴が一切変化しない
- [ ] 章内目次から該当問題へジャンプできる
- [ ] 最終章では「次の章を読む」ボタンが表示されない
- [ ] iPhone幅（375px程度）でレイアウト崩れなく読める
